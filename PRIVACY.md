# VaultOTP Privacy Policy

VaultOTP is a browser extension for generating and managing two-factor
authentication codes.

VaultOTP does not sell, rent, or share user data with advertisers or data
brokers.

## Data Stored by the Extension

VaultOTP may store the following data in the user's browser storage:

- Two-factor authentication account names
- OTP secrets added by the user
- User preferences
- Encryption settings
- Backup configuration

This data is stored locally in the browser, or in browser sync storage if the
user enables browser sync.

## Optional Cloud Backup

VaultOTP may allow users to back up their data to third-party storage providers,
such as Google Drive, Dropbox, or OneDrive.

Cloud backup is optional and only runs when the user enables or starts it. Data
sent to third-party providers is handled according to those providers' privacy
policies.

## Permissions

VaultOTP requests browser permissions only to provide its core features,
including generating codes, scanning QR codes, copying codes, autofill, browser
storage, optional backup, and auto-lock.

## Remote Code

VaultOTP does not download or execute remote JavaScript or WebAssembly code.

## Data Collection

VaultOTP does not collect analytics, browsing history, passwords, or
two-factor authentication secrets on developer-controlled servers.
